# Share-vs-isolate policy for guest assembly resolution — SINGLE SOURCE OF TRUTH, read by
# BOTH GuestAssemblyLoadContext (embedded resource) and the _IncludeGuestWasmAssemblies wasm
# payload filter in ToolkitSampleApp.csproj (ReadLinesFromFile). One rule per line:
#   =Name    share with the default ALC on exact simple-name match; excluded from the wasm payload
#   ^Prefix  share with the default ALC on prefix match; excluded from the wasm payload
#   ~Name    share on exact match if available in the default ALC; still shipped in the
#            payload so the guest can load it when it is unavailable to the host
#   !Prefix  ALWAYS isolate per-ALC on prefix match; always shipped. Isolation wins over sharing.
# Invariant: every =/^ name MUST be resolvable from the wrapper's default ALC at runtime
# (its own closure or the shared framework), or wasm guests fail to bind it.

# Repo-built theme libraries under test: deterministic isolation, even when the host has a
# same-named assembly loaded (the Uno SDK's Debug-only Hot Design tooling eagerly loads the
# *published* Uno.Themes.WinUI into the default ALC). Prefix match so *.Markup stays isolated.
!Uno.Toolkit
!Uno.Themes.WinUI
!Uno.Material.WinUI
!Uno.Cupertino.WinUI
!Uno.Simple.WinUI
